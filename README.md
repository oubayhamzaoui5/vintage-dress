# Vintage Dress

Vintage clothing storefront and admin dashboard built with React, Express, and MariaDB.

## Install and run on Windows

Install Git and Node.js 22 or newer. Open PowerShell and run:

```powershell
git clone https://github.com/oubayhamzaoui5/vintage-dress.git
cd vintage-dress
npm.cmd ci
npm.cmd run setup
npm.cmd run db:up
npm.cmd run seed
npm.cmd run seed:catalog
npm.cmd run dev
```

The first database start downloads and verifies portable MariaDB. The seed adds the principal admin and 36 dresses across six categories, with product photos bundled in the repo.

- Store: [http://127.0.0.1:5173](http://127.0.0.1:5173)
- Admin sign-in: [http://127.0.0.1:5173/login](http://127.0.0.1:5173/login)
- API health: [http://127.0.0.1:5000/api/health](http://127.0.0.1:5000/api/health)

Sign in as **Rania Attia** with **`admin@admin.com`** and **`azerty123`**. These credentials are for local demos. Configure your own admin credentials in `backend/.env` before seeding a deployed database.

## Daily use

Run `npm.cmd run db:up` and `npm.cmd run dev` from the project root. Press Ctrl+C to stop the app, then run `npm.cmd run db:stop` to stop MariaDB. The database persists in `.local/mysql-data`.

- Docker alternative: use `npm run db:docker` in place of `npm.cmd run db:up`, and `docker compose stop` to stop it. On macOS or Linux, use `npm` instead of `npm.cmd` throughout. The database listens locally on port 3307.
- Run `npm run build` to build the frontend.
- Local configuration is generated by `npm run setup`. On an existing checkout it preserves your `.env` files. Back up the database and `backend/uploads/products/` together to retain new product uploads.
- See the [API docs](backend/README.md), [demo guide](docs/MVP-AUDIT.md), and [photo credits](backend/uploads/demo/CREDITS.md).
